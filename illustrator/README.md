# Illustrator 自动调整排版脚本

`auto-layout.jsx`：字号改大（或改小）以后，一键重新整理排版，避免**重叠**和**中间空白太多**。

## 它会做什么

1. **区域文字框自动适应文字高度**：文字溢出（框右下角出现红色 ⊞）的框会加高，框里下面空一大截的会缩短。
2. **同一行左右重叠 → 往右推开**：比如标题变长后压到右边的图标，图标会被推到标题右边。
3. **上下排列重新整理**：从上往下依次排，每个元素放在它上面那个元素的下方：
   - 重叠、太挤（小于「最小间距」）的 → 拉开到最小间距
   - 空白太大（大于「最大间距」）的 → 收紧到最大间距
   - 在范围内的间距 → 保持原样（保留原来的疏密节奏）
   - 两栏 / 多栏排版：各栏分别往下排，横跨多栏的元素会排在最长那栏下面
4. **整体位置**（三选一）：
   - 最上面的元素不动，往下排
   - 撑满画板：多出来的空白平均分到每个间距，底部留白 = 顶部留白
   - 整体在画板内上下居中

## 安装和使用

1. 下载 [`auto-layout.jsx`](./auto-layout.jsx)：打开文件页面，点右上角的下载按钮（Download raw file）。
   **请直接下载文件，不要复制粘贴代码**，否则中文可能会乱码。
2. 在 Illustrator 里打开你的文件，**先保存一下**。
3. 菜单 **文件 > 脚本 > 其他脚本…**（Windows：`Ctrl+F12`，Mac：`⌘F12`），选中 `auto-layout.jsx`。
4. 在弹出的窗口里设置好，点「开始调整」。
5. 不满意就 `Ctrl+Z` / `⌘Z` 撤销，改改间距再运行一次。

> 想让它一直出现在「文件 > 脚本」菜单里：把文件放进 Illustrator 安装目录下的 `Presets/zh_CN/脚本`（英文版是 `Presets/en_US/Scripts`），重启 Illustrator。

## 设置说明

| 设置 | 说明 |
| --- | --- |
| 处理范围 | 「只处理选中的对象」或「当前画板上的所有对象」 |
| 单位 | pt 或 mm |
| 最小间距 / 最大间距 | 每个上下间距都会被限制在这个范围内；两个数填一样 = 所有间距统一 |
| 整体位置 | 见上面第 4 点 |
| 区域文字框高度自动适应 | 默认打开 |
| 同一行左右重叠时往右推 | 默认打开 |

设置会自动记住，下次打开还是上次的值。

## 使用技巧

- **要一起移动的东西请先编组**（`Ctrl+G` / `⌘G`），比如：图片 + 压在图片上的文字、卡片底色 + 卡片里的内容、图标 + 旁边的小字。编组后脚本会把它当成一个整体。
- 文字 / 图形如果有 80% 以上落在某个形状或图片里面，脚本也会自动认为它们是一起的。
- **铺满画板（85% 以上）的背景**会自动识别，不会被移动。
- **锁定或隐藏的对象**不会被移动（注意：它们也不会被当成障碍物，内容可能会排到它们上面）。
- 选「只处理选中的对象」时，没选中的对象不参与计算。

## 目前的限制

- 编组里面的元素不会单独重新排（编组当作一个整体）。
- 只会往右推、往下推，不会自动换行、也不会自动缩小字号。如果内容超出画板，脚本会提示超出多少。
- 串接的文字框、旋转过的文字框、圆形等不规则形状的文字框不会自动调整高度。
- 点文字（单击输入、没有框的文字）会随字号自动变大，不需要调整高度，脚本会直接按它的实际大小排版。

## 遇到问题

脚本出错时会弹出提示（包括第几行）。把提示截图，连同出问题的画板截图一起发过来，就可以针对你的版式修改脚本。
